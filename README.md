# Demon Hunters (working title)

Co-op horde-survival roguelike. Prototype #1.

## Required reading (in order)

1. `DESIGN-PILLARS.md` — what the full game is.
2. `PROTOTYPE-SCOPE.md` — what we're building right now.
3. `CLAUDE.md` — how we work in this repo.

## Run

```
npm install
npm run dev         # Vite dev server, localhost
npm run build       # production build
npm run typecheck   # tsc --noEmit
```

See `CLAUDE.md` for everything else.
